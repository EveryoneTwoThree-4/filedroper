# FileDrop — передача файлов между телефоном и компьютером

## Возможности
- Загрузка файла с телефона или компьютера.
- Шестизначный код для получения файла на другом устройстве.
- Поиск файла по коду и скачивание.
- Прогресс загрузки.
- Автоматическое удаление через 24 часа.
- Ограничение размера файла (по умолчанию 1 ГБ).

## Запуск на компьютере
Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

Откройте http://localhost:3000

## Публикация в интернете
Разместите проект на сервере с Node.js (например, VPS или платформе, поддерживающей Node.js).
Укажите команду запуска `npm start`.

**Важно про хранение:** папка `data` содержит загруженные файлы и метаданные. На хостинге подключите постоянный диск (persistent volume) и задайте `DATA_DIR` на этот диск. Без постоянного диска некоторые хостинги удаляют загруженные файлы при перезапуске или пересборке приложения.

## Настройки через переменные окружения
- `PORT` — порт сервера (обычно задаётся хостингом).
- `DATA_DIR` — каталог для хранения файлов; по умолчанию `./data`.
- `MAX_FILE_BYTES` — максимальный размер файла в байтах; по умолчанию 1 ГБ.

## Перед публичным запуском
Это стартовая версия. Для публичного сервиса с важными или личными файлами добавьте авторизацию/защиту от перебора кодов, антивирусную проверку, объектное хранилище и HTTPS. Не загружайте конфиденциальные файлы на непроверенный сервер.
